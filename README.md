`Python` · `SQL` · `Tableau` · `Excel` · `Data Warehousing`

- Analyzed shipping performance metrics including on-time deliveries, failed shipments, and delay patterns.
- **Key Findings:** ~45% on-time delivery rate, ~20% failed delivery rate, and an average delay of 35+ minutes on the dataset.

- Built a real-time status pipeline: `Pending` ➔ `In Progress` ➔ `Resolved`.

`Python` · `Flask` · `TF-IDF` · `Scikit-Learn` · `Logistic Regression`
